## 测试点脑图（文本版）

```
AI 心理咨询模块
├── 流式对话
│   ├── 正向：正常输入输出 + 打字机流式渲染
│   ├── 异常：空输入 / 输入中重复发送 / 超长输入 / 特殊字符
│   └── 异常：断网中断 / 超时(5000ms)
├── 情绪分析（情绪花园）
│   ├── 正向：正常展示主要情绪 + 评分 + 强度
│   ├── 反向：正面情绪(isNegative=false) vs 负面情绪(isNegative=true) 显示差异
│   └── 反向：极端负面情绪 → 风险预警提示（重点）
└── 会话管理
    ├── 新建会话 / 会话列表新增
    ├── 切换会话（历史消息回显）
    └── 删除会话（含列表刷新）
```

## 执行说明

1. **TC_CHAT_012（风险预警）是本模块核心亮点**，触发条件为"负面情绪且风险等级>1"。务必输入明确的极端负面语句，触发后**完整截图**（含风险提示卡片内容）。

2. **TC_CHAT_007 / 008（SSE 断网/超时）是本项目特色**，若依没有。断网用「开发者工具 → Network → Offline」模拟；超时用「Network → Throttling → Slow」或手动断后端模拟。

3. **情绪花园依赖后端情绪分析接口**（`GET /session/{id}/emotion`）。若情绪花园不更新，先确认是"前端不展示"还是"接口未返回情绪数据"，区分功能缺陷与接口环境问题。

4. **会话 ID 前缀**：源码中会话 ID 会拼接 `session_` 前缀，若切换/删除会话异常，可从 Network 面板查看 sessionId 格式是否正确。
