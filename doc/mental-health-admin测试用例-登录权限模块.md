## 执行说明

1. **管理员相关用例（TC_AUTH_002 / 018）**：若管理员账号（userType=2）信息不明，标记 **Blocked** 并在备注说明"管理员账号未提供"，这是外部共享后端的客观限制，面试时可主动说明。
2. **越权用例（TC_AUTH_016）是本模块核心亮点**，与若依的"权限控制"形成差异——本项目验证的是"前端路由守卫双端隔离"，务必完整截图留证。
3. **Token 持久化验证（TC_AUTH_005）**：确认 localStorage 中存在 `token` 字段，刷新后仍存在。

## 接口测试（本模块）

> **工具**：Postman  
> **关键约定**（来自源码 `request.js`，务必遵守）：
> - 认证请求头字段名为 `token`（**非** `Authorization`）
> - 响应 `code` 为**字符串** `"200"`（成功）/ `"-1"`（失败），**非数字**
> - 响应结构统一为 `{ code, msg, data }`

**Token 获取方法**：先调 `POST /user/login` 登录成功 → 从响应 `data.token` 取值 → 后续请求在 Header 添加 `token` 字段。

| 用例ID | 方法 + 路径 | 测试点 | 请求说明 | 预期结果 | 实际结果 | 测试结果 |
|--------|-------------|--------|----------|----------|----------|----------|
| IF_AUTH_001 | POST /user/login | 正常登录 | 传入正确 username + password | 返回 `code:"200"`，`data.token` 非空 | | |
| IF_AUTH_002 | POST /user/login | 错误密码 | 正确 username + 错误 password | 返回 `code:"-1"`，msg 提示账号或密码错误 | | |
| IF_AUTH_003 | POST /user/login | 空参数 | username/password 留空或缺失 | 返回错误码，不返回 500 | | |
| IF_AUTH_004 | POST /user/logout | 无 token 鉴权 | Header 不携带 `token` 字段 | 被拦截，返回 `code:"-1"` 或 401，不报 500 | | |
| IF_AUTH_005 | POST /user/add | 缺 email 参数 | 注册时不传 email 字段 | 后端返回校验错误，友好提示，不报 500 | | |
| IF_AUTH_006 | POST /user/add | 非法邮箱格式 | email 传 "abc"（无 @） | 后端校验邮箱格式并返回错误；若不校验则记缺陷 | | |
| IF_AUTH_007 | GET /psychological-chat/sessions | 无 token 访问需认证接口 | Header 不携带 `token` 字段 | 返回 `code:"-1"` 或 401，不返回数据 | | |

> **说明**：IF_AUTH_004/005/006/007 是功能测试点不到的"后端独立校验"场景，是本模块接口测试的核心价值所在。
